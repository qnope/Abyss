# Translations

`lib/presentation/l10n/` — the game's texts in French, English and Spanish.

## Files

| File | Role |
|------|------|
| `app_fr.arb` | Source texts, in French. Every new text starts here, with its placeholder metadata. |
| `app_en.arb`, `app_es.arb` | The same keys, translated. |
| `app_localizations*.dart` | Generated by `flutter pub get` from the ARB files (see `l10n.yaml`). Never edit by hand. |
| `abyss_locale.dart` | The supported languages and how the device picks one. |
| `l10n_extension.dart` | `context.l10n`, the shortcut every widget uses. |

## Which language

Only the first language of the device counts: French gives French, Spanish
(any country) gives Spanish, anything else gives English.

## Writing a text

1. Add the key to `app_fr.arb`, named after its screen or subject
   (`newGameStart`, `difficultyTitle`), with an `@key` entry declaring its
   placeholders. Plurals use ICU syntax (`{count, plural, =1{…} other{…}}`).
2. Add the same key to `app_en.arb` and `app_es.arb`. Player-facing advice
   says "tu" in French, "you" in English and "tú" in Spanish.
3. Read it with `context.l10n.key` in the widget.

`test/presentation/l10n/arb_files_test.dart` fails when a language misses a
key, has an extra one, or drops a placeholder, and
`no_french_literals_test.dart` fails when a screen writes an accented text
itself instead of reading it from the translations.

French punctuation keeps its space before `:`, `;`, `!` and `?`
("Stock : 3"); English and Spanish do not.

## Tests

`context.l10n` falls back to the French texts when no translations are
loaded, so a widget test with a bare `MaterialApp` keeps reading French.
`test/helpers/localized_app.dart` loads the real translations for tests that
check another language.
