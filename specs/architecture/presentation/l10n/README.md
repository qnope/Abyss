# Translations

`lib/presentation/l10n/` — the game's texts in French, English and Spanish.

## Files

| File | Role |
|------|------|
| `app_fr.arb` | Source texts, in French. Every new text starts here, with its placeholder metadata. |
| `app_en.arb`, `app_es.arb` | The same keys, translated. |
| `app_localizations*.dart` | Generated by `flutter pub get` from the ARB files (see `l10n.yaml`). Never edit by hand. |
| `abyss_locale.dart` | The supported languages and how the device picks one. |
| `l10n_extension.dart` | `context.l10n`, the shortcut every widget uses. |
| `language_choice_locale.dart` | `LanguageChoice.locale`: the locale a player's choice forces, null for automatic. |
| `language_scope.dart` | `LanguageScope`, giving every screen the player's `LanguageSettings`. |

## Which language

By default (`LanguageChoice.automatic`) the device decides, and only its
first language counts: French gives French, Spanish (any country) gives
Spanish, anything else gives English.

The player can force French, English or Spanish instead. The choice lives
in `LanguageSettings` (data layer, saved in the `settings` Hive box).
`AbyssMaterialApp` (`lib/presentation/abyss_material_app.dart`) rebuilds only
its `MaterialApp` when the choice changes, setting `locale` to the forced
language or to null for automatic, so the switch is immediate. Picking
automatic again hands the language back to the device.

Any screen reads or changes the choice through
`LanguageScope.maybeOf(context)?.choose(choice)`; `maybeOf` returns null in
an app built without settings, as in most widget tests.

The player picks it in the `LanguagePicker` (`widgets/common/`), shown in
the in-game settings and behind the gear of the home screen. Its language
rows are endonyms ("Français", "English", "Español", from
`extensions/language_choice_extensions.dart`): they stay the same in every
language, so they are constants rather than ARB texts, and that file is
allowed by `no_french_literals_test.dart`.

## Writing a text

1. Add the key to `app_fr.arb`, named after its screen or subject
   (`newGameStart`, `difficultyTitle`), with an `@key` entry declaring its
   placeholders. Plurals use ICU syntax (`{count, plural, =1{…} other{…}}`).
2. Add the same key to `app_en.arb` and `app_es.arb`. Player-facing advice
   says "tu" in French, "you" in English and "tú" in Spanish.
3. Read it with `context.l10n.key` in the widget.

`test/presentation/l10n/arb_files_test.dart` fails when a language misses a
key, has an extra one, or drops a placeholder, and
`no_french_literals_test.dart` fails when a screen writes an accented text
itself instead of reading it from the translations.

French punctuation keeps its space before `:`, `;`, `!` and `?`
("Stock : 3"); English and Spanish do not.

## Tests

`context.l10n` falls back to the French texts when no translations are
loaded, so a widget test with a bare `MaterialApp` keeps reading French.
`test/helpers/localized_app.dart` loads the real translations for tests that
check another language. `test/helpers/language_settings_harness.dart` gives
real `LanguageSettings`; `chooseLanguage` and `tapLanguage` write the choice
with real file access (`tester.runAsync`), so Hive never hangs a test.
